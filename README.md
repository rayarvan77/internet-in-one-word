The whole internet, summed up in a single word: **Doomscrolling**.

It is the one habit the entire internet shares. Bad news, funny videos,
arguments with strangers, one more swipe at 2 AM — a noun, a verb, a
diagnosis, and a confession at once. The entry is that word and nothing
else, exactly as the bounty asks. No files, no code, no links — just the
word, printed by the program so the entry stays deterministic.

## Run it

```sh
python3 main.py
```
